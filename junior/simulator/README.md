# Simulator

A software stand-in for the floor unit: a display, eight patch switches in a
row, and song up/down switches set apart. Selecting a song loads switch 1's
patch; mapped switches light blue and the active one green.

Not started as a shared component. The BOSS GT-1000 proof of concept in
[../devices/boss_gt-1000/](../devices/boss_gt-1000/) has a working simulator
page in `setlist/templates/setlist/unit.html`; the device-neutral version will
be extracted from it.
